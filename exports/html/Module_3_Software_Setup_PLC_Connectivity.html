Lesson: IP Address Configuration

  • Setting your laptop IP to communicate with PLCs on any subnet

IP Address Configuration (content)

  • Every PLC connection starts with IP address configuration. Your laptop must be on the same subnet as the PLC to communicate.
  • → Step-by-Step: Setting Your IP Address
  • • Open the Windows search bar and type Network Connections
  • • Double-click the Ethernet adapter showing "Unidentified Network" (this is the one connected to the PLC)
  • • Click Properties, enter your username and password if prompted
  • • Scroll to Internet Protocol Version 4 (TCP/IPv4) and double-click
  • • Select Use the following IP address
  • • Set the first three octets to match the PLC's IP. Set the last octet to a unique number (not the PLC's address). Example: PLC is 192.168.1.100 → set laptop to 192.168.1.50
  • • Set Subnet mask to 255.255.255.0
  • • Click OK and close all dialogs

IP Address Configuration (content)

  • [INFO] Subnet Explained Simply: With a subnet mask of 255.255.255.0, the first three number groups must match between your laptop and the PLC. Only the last number must be different. If the PLC is 192.168.5.20, your laptop could be 192.168.5.50 — but NOT 192.168.1.50 (different third octet).
  • → Verify Connectivity with Ping
  • Open Command Prompt and type: ping 192.168.1.100 (replace with the PLC's actual IP). You should see replies. If you see "Request timed out" or "Destination host unreachable," check your IP settings, cable, and link lights.
  • [TIP] IT Access Requirement: Changing your IP address requires permission. Reference SR-128857 in self-service. One approval covers all three PLC platforms.

Lesson: Connecting to Omron (Sysmac Studio)

  • Direct Ethernet and remote connection procedures for Omron NX1P2

Connecting to Omron (Sysmac Studio) (content)

  • Sysmac Studio is Omron's integrated development environment for the NX/NJ series controllers. Request it via self-service using references SR-124812 and SR-117625.
  • → Direct Ethernet Connection
  • • Plug the Ethernet cable from your laptop directly into the PLC's Ethernet port
  • • Open Sysmac Studio and open or create a project
  • • Select Direct Connection via Ethernet in the connection dialog
  • • Click Connect — the software will scan for controllers on the subnet
  • • If prompted, select the correct controller from the discovered list
  • → Remote Connection
  • • Select Remote Connection via Ethernet
  • • Enter the PLC's IP address in the connection settings

Connecting to Omron (Sysmac Studio) (content)

  • • Ensure your laptop's IP address has the same first three octets
  • • Click Connect
  • If Ethernet fails, try Direct Connection via USB as a backup — connect a USB cable from your laptop to the PLC's USB port.
  • → Verifying Online Status
  • When connected, the Sysmac Studio toolbar shows a green 'Online' indicator. The project tree updates to show the live controller status. Verify the RUN LED on the physical PLC matches what software reports.

Lesson: Connecting to Allen Bradley (Studio 5000)

  • Who Active, going online, and navigating Studio 5000

Connecting to Allen Bradley (Studio 5000) (content)

  • Studio 5000 Logix Designer is the programming environment for Allen Bradley CompactLogix and ControlLogix controllers. Request via self-service (reference SR-124812). IT installs via BeyondTrust.
  • → Connection Steps
  • • Set your IP address to the same subnet as the controller (e.g., PLC is 192.168.1.100, set laptop to 192.168.1.50)
  • • Open Studio 5000 and open the project file (.ACD)
  • • Go to Communications > Who Active (or press Ctrl+W in RSLinx)
  • • Expand the Ethernet driver to browse the network — the controller should appear
  • • Right-click the controller and select Go Online
  • • The software will compare the offline project to the online program — review any differences
  • [WARNING] Online vs. Offline Mismatch: If the offline project doesn't match what's in the controller, Studio 5000 will warn you. Always upload from the controller first to get the current program before making changes.

Lesson: Connecting to AutomationDirect (Productivity Suite)

  • Ethernet connection and program access for Productivity PLCs

Connecting to AutomationDirect (Productivity Suite) (content)

  • Productivity Suite is free to download from AutomationDirect.com. Confirm the version matches the PLC firmware (P1000, P2000, or P3000 series).
  • → Connection Steps
  • • Connect an Ethernet cable from your laptop to the PLC's Ethernet port (or a switch on the same network)
  • • Set your IP to the same subnet as the PLC
  • • Open Productivity Suite and select Connect from the toolbar
  • • Enter the PLC's IP address when prompted
  • • The software connects and shows the live program status
  • → Viewing Live Data
  • Once online, go to View > Data View to see a live table of all tag values — I/O points, memory bits, timers, and counters. Filter by name to find specific tags.

Lesson: Program Backup & Restore

  • How to upload (backup) and download programs — the most important habit you'll build

Program Backup & Restore (content)

  • [DANGER] The #1 Rule: ALWAYS upload (backup) the current program from the PLC to your laptop BEFORE making any changes. This is non-negotiable on production machines.
  • → Uploading (Backup) a Program
  • Uploading reads the current program from the PLC to your laptop. Do this every time before you modify anything.
  • Table: Platform | Steps
  • • Omron Sysmac Studio | Go online → Transfer > Upload from Controller → Save project with descriptive name
  • • AB Studio 5000 | Go online → Upload → Save .ACD file with date and machine name
  • • Productivity Suite | Connect → File > Read Project from PLC → Save with descriptive name
  • → File Naming Convention
  • Use a consistent naming format: [MachineName]_[PLCType]_[Date]_[Reason].ext
  • Example: CobotReamer_NX1P2_20260407_PreMaintenance.smc2

Program Backup & Restore (content)

  • → Downloading (Restore) a Program
  • Downloading writes a program from your laptop to the PLC. This replaces the running program and is only done for intentional changes or restoration after a failure.
  • [WARNING] Production Impact: Downloading to a production PLC will interrupt the running program. Coordinate with production before any download. On the training bench, downloads are safe to practice.

Lab: Physical Connection Walkthrough

  • After: IP Address Configuration
  • Duration: 10 min
  • Physically connect an Ethernet cable from laptop to the Omron NX1P2. Show link lights on both ends. Open Command Prompt, ping the PLC — show success. Change one octet to demonstrate a failed ping.
  • Students take turns plugging in the cable, verifying link lights, and running a ping test. Each experiences at least one failed and one successful ping.

Lab: Live Online — All Three Platforms

  • After: Connecting to AutomationDirect (Productivity Suite)
  • Duration: 15 min
  • With the laptop connected, go online with each platform in sequence: Sysmac Studio → NX1P2, Studio 5000 → CompactLogix, Productivity Suite → P2000. Show the online indicator and matching RUN LED.
  • Students note the different workflows for each platform and observe visual confirmation (software indicator + physical LED).

Lab: Program Upload (Backup)

  • After: Program Backup & Restore
  • Duration: 10 min
  • Perform a full upload from PLC to laptop. Save with a proper filename. Show file location. Emphasize: do this EVERY TIME before changing anything on production equipment.
  • Students perform the upload on at least one platform and verify the saved file exists.
