Lesson: PLC Cabinet Overview

  • Major components and their functions inside a PLC control cabinet

PLC Cabinet Overview (content)

  • A PLC (Programmable Logic Controller) checks signals from sensors or switches (inputs), runs through a set of programmed instructions based on those inputs and logic, and controls motors, lights, valves, or conveyors (the outputs).
  • The PLC cabinet houses all the core control components. Understanding what's inside — and what each component does — is the foundation of every troubleshooting task.
  • → PLC CPU Controller
  • [Figure] PLC CPU (example: Siemens SIMATIC S7-1200) — the brain of the system; your site may use Omron, Allen-Bradley, or AutomationDirect processors
  • The CPU is the brain of the PLC. It executes the ladder logic program in a continuous scan cycle: read all inputs → execute program logic → update all outputs → repeat. The scan time (typically 1–20ms) determines how fast the PLC responds to changes.
  • • RUN LED: Solid green = program is executing normally
  • • ERR LED: Flashing red = minor fault, solid red = major fault (CPU halted)
  • • Mode switch: Selects RUN, PROGRAM, or REMOTE mode
  • [INFO] PLC Operating Modes: RUN: Normal operation — program executes, outputs are active.PROGRAM: Program is halted — outputs are de-energized. Used for downloading programs.REMOTE: Mode can be changed from software. Most common setting for production machines.
  • → Power Supply

PLC Cabinet Overview (content)

  • [Figure] DIN-rail 24 V DC power supply — converts facility AC to 24 VDC for the PLC and field I/O
  • The power supply converts facility AC voltage (120VAC or 240VAC) to 24VDC for the PLC modules and field devices. Key specs to note: input voltage range, output current capacity, and whether it has redundancy or short-circuit protection.
  • → Ethernet Communication Board
  • [Figure] Industrial Ethernet hardware (example: Siemens ESM, 8× RJ45) — EtherNet/IP, Modbus TCP, and EtherCAT use similar Ethernet ports and link/activity LEDs
  • Enables EtherNet/IP or EtherCAT communication between the PLC, HMI screens, other PLCs, and engineering workstations. Check the link and activity LEDs to verify connectivity.
  • → PLC Families On Site
  • Table: Platform | CPU Model | Protocol | Software
  • • Omron | NX1P2, CP1L | EtherCAT | Sysmac Studio
  • • Allen Bradley | CompactLogix | EtherNet/IP | Studio 5000
  • • AutomationDirect | Productivity P2000 | Modbus TCP | Productivity Suite

Lesson: Digital I/O Modules

  • Digital input and output cards — wiring, diagnostics, and replacement

Digital I/O Modules (content)

  • → Digital Input Modules (DI Cards)
  • Digital input modules accept discrete on/off signals (typically 24VDC). Each channel reads a binary state — 1 (ON/TRUE) or 0 (OFF/FALSE). Field devices like sensors, switches, and push buttons wire to the module's screw terminals.
  • • Sinking vs. Sourcing: Sinking inputs accept current (NPN sensors provide current path to ground). Sourcing inputs provide current (PNP sensors switch the positive supply). Most modern PLCs auto-detect, but wiring errors between NPN/PNP cause phantom signals.
  • • Channel LEDs: Each input channel has an LED — green/lit means that input is seeing a signal (ON). This is your first diagnostic tool.
  • • Common grouping: Inputs may share a common terminal in groups of 4, 8, or 16. If the common wire breaks, the entire group goes dead.
  • [TIP] Quick Diagnostic: If a sensor's own LED is lit but the PLC input module LED is dark, the problem is between the sensor and the module — check wiring, terminal connections, and fuses.
  • → Digital Output Modules (DO Cards)
  • Digital output modules drive discrete on/off loads. The PLC sets output bits to ON/OFF, and the module energizes or de-energizes the corresponding terminal.
  • Table: Output Type | Characteristics | Best For
  • • Relay | Mechanical contact, audible click, handles AC or DC, higher current (2A+) | Motor contactors, solenoid valves, mixed-voltage loads

Digital I/O Modules (content)

  • • Transistor (sinking/sourcing) | Solid-state, silent, DC only, fast switching, lower current | High-speed applications, indicator lights, low-current solenoids
  • • Triac | Solid-state, AC only, silent, moderate speed | AC-powered devices, heaters
  • [WARNING] Common Failure Mode: Relay output contacts wear over time (especially with inductive loads). If an output module LED is lit but the connected device doesn't respond, measure voltage at the output terminal — a worn relay contact may show high resistance or no continuity.

Lesson: Analog I/O Modules

  • Analog input and output modules — signal types, scaling, and calibration

Analog I/O Modules (content)

  • → Analog Input Modules (AI Cards)
  • Analog input modules read continuous signals rather than simple on/off states. They convert real-world measurements (pressure, temperature, flow, position) into digital values the PLC can process.
  • Table: Signal Type | Range | Common Use
  • • 4–20mA | Current loop | Pressure transmitters, level sensors, flow meters — most common industrial standard
  • • 0–10VDC | Voltage | Potentiometers, some sensor outputs, speed references
  • • 0–5VDC | Voltage | Legacy sensors, some load cells
  • • Thermocouple | mV (type-specific) | Temperature measurement (requires TC-specific module)
  • • RTD | Resistance | Precision temperature measurement (requires RTD-specific module)
  • [INFO] Why 4–20mA Instead of 0–20mA?: The 4mA "live zero" is intentional — if you read 0mA, it means a broken wire, not a zero reading. This is the single most useful diagnostic feature of the 4–20mA standard.
  • → Analog Output Modules (AO Cards)

Analog I/O Modules (content)

  • Analog output modules generate continuous control signals. The PLC writes a value, and the module outputs a proportional voltage or current signal to control devices like VFDs, proportional valves, or chart recorders.
  • • 4–20mA output: Used for driving valve positioners and remote setpoints. 2-wire vs. 4-wire configurations matter for wiring.
  • • 0–10VDC output: Common for VFD speed references and dimmer controls.
  • • Scaling: The PLC stores values as raw integers (e.g., 0–4095 for 12-bit, 0–65535 for 16-bit). The program scales this to engineering units.
  • [TIP] Troubleshooting Analog Signals: Use a milliamp clamp meter or process calibrator to verify the actual signal at the terminal. If the PLC shows a good value but the field device isn't responding, the problem is downstream. If the PLC shows an out-of-range value, check the wiring and transmitter.

Lesson: Cabinet Infrastructure

  • DIN rail, fuses, grounding, power distribution, and wire labeling

Cabinet Infrastructure (content)

  • → DIN Rail Mounting
  • 35mm top-hat DIN rail (EN 60715) is the universal standard for mounting PLC modules, terminal blocks, relays, circuit breakers, and power supplies. Every component in the cabinet sits on it.
  • • Modules clip onto DIN rail via a spring-loaded tab at the bottom
  • • To remove: insert a flat-blade screwdriver into the release tab and lever the module forward
  • • Ensure proper spacing between components for heat dissipation per manufacturer specs
  • → Fuses & Circuit Breakers
  • Fuses and miniature circuit breakers (MCBs) protect the PLC power supply, output modules, and field devices from overcurrent. A blown fuse is one of the most common and easiest-to-fix causes of apparent PLC output failures.
  • [DANGER] Check Fuses First!: Before chasing a software problem, always check physical fuses. A blown fuse on an output circuit makes the PLC output appear to fail — the PLC commands the output ON (LED is lit on the module), but the field device doesn't respond because the fuse is blown.
  • → 24VDC Power Distribution
  • The 24VDC output from the PLC power supply must be distributed to input modules, sensors, and some output devices. This is done via power distribution terminal blocks or fused distribution blocks. A single shorted sensor can drag down the entire 24VDC bus if distribution is not fused — taking out dozens of inputs simultaneously.

Cabinet Infrastructure (content)

  • → Grounding & Bonding
  • Proper earth grounding prevents analog signal noise, intermittent communication faults, false input triggers, and ESD damage. Key practices:
  • • Star-point grounding: All ground wires connect to a single ground bus bar, which connects to building ground
  • • Cable shield grounding: Shield drain wires land on the ground bus at one end only to avoid ground loops
  • • DIN rail grounding: DIN rail is bonded to the cabinet ground bus
  • • Separate safety earth from signal/analog ground references
  • → Wire Labeling & Cable Management
  • Proper wire labeling using heat-shrink markers or wrap-around labels matched to the wiring diagram is critical for maintenance. When you open a cabinet at 2 AM during an emergency, labeled wires are the difference between a 15-minute fix and a 4-hour nightmare.
  • • Wire duct (Panduit) keeps wires organized and accessible
  • • Ferrules on stranded wire ends prevent fraying and loose connections

Cabinet Infrastructure (content)

  • • Every wire should be labeled at both ends matching the wiring diagram
  • → Main Disconnect Switch
  • The main power disconnect on the cabinet door is the primary LOTO point. It's required by NFPA 79 and NEC. Always verify zero energy after turning off the disconnect — some circuits (UPS-fed or external convenience outlets) may remain live.

Lab: Live Cabinet Identification

  • After: PLC Cabinet Overview
  • Duration: 10 min
  • Walk to the tabletop bench. Trainer points to each major component: power supply (show input voltage label, output 24VDC), CPU module (show RUN/ERR LEDs, mode switch), Ethernet port (show link/activity LEDs).
  • Each student physically points to and names: the CPU on each of the three PLCs, the power supply, and at least one input and one output module.

Lab: Wiring Trace Exercise

  • After: Digital I/O Modules
  • Duration: 15 min
  • Pick one input device (e.g., proximity sensor). Starting at the sensor, physically trace the wire through cable duct to the terminal block, then to the I/O module terminal. Show the wiring diagram side-by-side.
  • Students each select a different device and trace its wiring from device → terminal block → I/O module, then report which terminal block number, I/O slot, and channel.

Lab: Three-Platform Comparison

  • After: Cabinet Infrastructure
  • Duration: 10 min
  • Stand at the bench with all three PLCs visible. Point out physical differences: module form factor, how I/O attaches, Ethernet ports, DIP switches, and size differences.
  • Students note one physical difference between platforms they find surprising. Brief group discussion.

  • Zero pressure — everything is normal | A broken wire or disconnected transmitter | The transmitter is reading negative pressure | The analog module is faulty
