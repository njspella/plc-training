Lesson: Ladder Logic Building Blocks — Part 1

  • Core instructions: contacts, coils, latches, timers, and counters

Ladder Logic Building Blocks — Part 1 (content)

  • → Contacts and Coils
  • Table: Instruction | Symbol | Function
  • • Normally Open (XIC/NO) | --[ ]-- | Passes power when the referenced bit is ON (1). Checks if an input is active.
  • • Normally Closed (XIO/NC) | --[/]-- | Passes power when the referenced bit is OFF (0). Blocks logic when a fault/interlock is active.
  • • Output Coil (OTE) | --( )-- | Sets the referenced bit ON when the rung has power. Turns OFF when power is lost.
  • • Latch (OTL) | --(L)-- | Sets the bit ON and it stays ON even after the rung loses power. Requires an unlatch to turn off.
  • • Unlatch (OTU) | --(U)-- | Turns off a latched bit. Used in pairs with OTL for start/stop logic.
  • → Timers
  • Table: Timer | Function | Common Use
  • • TON (Timer On-Delay) | Starts counting when rung is true. DN bit turns ON after preset time. | Debounce sensors, sequence delays, dwell times

Ladder Logic Building Blocks — Part 1 (content)

  • • TOF (Timer Off-Delay) | Starts counting when rung goes false. DN bit stays ON for preset time after rung goes false. | Cooldown periods, coast-down timing
  • • RTO (Retentive Timer) | Like TON but accumulator retains value when rung goes false. Must use RES to reset. | Total run-time tracking, accumulated process time
  • → Counters
  • Table: Counter | Function | Common Use
  • • CTU (Count Up) | Increments by 1 each time the rung transitions from false to true. DN bit turns ON at preset. | Part counting, cycle counting
  • • CTD (Count Down) | Decrements by 1 each transition. DN bit turns ON when accumulator reaches zero. | Batch remaining count, magazine count

Lesson: Ladder Logic Building Blocks — Part 2

  • Comparison, math, move instructions, and other function blocks

Ladder Logic Building Blocks — Part 2 (content)

  • → Comparison Instructions
  • Comparison instructions evaluate two values and pass power if the condition is true:
  • Table: Instruction | Meaning | Example
  • • EQU | Equal | Check if counter = target value
  • • NEQ | Not Equal | Check if status flag has changed
  • • GRT | Greater Than | Check if temperature exceeds limit
  • • LES | Less Than | Check if pressure is below minimum
  • • GEQ | Greater Than or Equal | Check if timer accumulator >= setpoint
  • • LEQ | Less Than or Equal | Check if speed is within range
  • → Math & Move Instructions

Ladder Logic Building Blocks — Part 2 (content)

  • • MOV (Move): Copies a value from Source to Destination. Used for loading setpoints, copying recipes, and resetting accumulators.
  • • ADD / SUB / MUL / DIV: Arithmetic on tag values. Used for scaling analog signals, calculating rates, and batch arithmetic.
  • • CPT (Compute): Evaluates a formula expression. Useful for complex calculations in a single instruction.

Lesson: Servo Motor Configuration

  • Setting up servo axes in Omron Sysmac Studio over EtherCAT

Servo Motor Configuration (content)

  • → Adding a Servo Axis
  • • In the Sysmac Studio project tree, go to Motion Control > Axes
  • • Right-click and add a new Servo Axis
  • • Assign it to the EtherCAT node number matching the physical drive (check drive's rotary switches or DIP settings)
  • → Unit Conversion Settings
  • Under Axis Parameters > Unit Conversion, configure:
  • • Encoder pulses per revolution
  • • User units (mm, degrees, inches) per motor revolution
  • • Gear ratio if a gearbox is present
  • → Key Parameters

Servo Motor Configuration (content)

  • Table: Parameter | What It Controls | Risk if Wrong
  • • Max Velocity | Speed limit for the axis | Too fast = mechanical damage, too slow = cycle time loss
  • • Acceleration / Deceleration | Ramp rates | Too aggressive = motor faults, too gentle = slow response
  • • Position Limits | Software travel limits | Prevents axis from moving beyond mechanical range
  • • Torque Limit | Maximum motor force | Too high = potential to damage tooling or workpiece
  • [WARNING] Parameter Changes on Production: Never change servo parameters on a production machine without comparing to the documented values first. Small changes to acceleration or position limits can cause crashes, product damage, or injury.

Lesson: Global Variables & Adding Components

  • Creating global variables, naming conventions, and adding I/O modules

Global Variables & Adding Components (content)

  • → Creating Global Variables
  • Global variables are accessible from any program block in the PLC project. In Omron Sysmac Studio, define them in the Global Variable Table. In Allen Bradley Studio 5000, these are Controller-scoped tags.
  • → Naming Convention
  • Use a function area prefix for instant clarity:
  • • SAFETY_ — E-stop, safety relay, scanner signals
  • • MOTION_ — Servo axis commands and feedback
  • • HMI_ — Operator interface signals
  • • CONV_ — Conveyor system signals
  • • IO_ — General I/O points
  • → Adding I/O Components

Global Variables & Adding Components (content)

  • Table: Platform | Steps
  • • Omron (EtherCAT) | Right-click EtherCAT master > Add Slave. Select from ESI library. Assign node address. Map tags to I/O channels in the I/O Map view.
  • • Allen Bradley | Right-click I/O Configuration > New Module. Search by catalog number. Set IP address and slot. Download and verify in I/O tree.
  • • AutomationDirect | Use the I/O Configuration wizard in Productivity Suite. Select module type, assign slot, map tags.

Lab: Servo Parameters — Live Adjustment

  • After: Servo Motor Configuration
  • Duration: 15 min
  • On the EtherCAT servo drive, show current parameters. Make a safe change (reduce velocity by 50%), command a move, observe the difference. Restore original.
  • Students read parameters, predict what a change will do, observe the result, then restore. Reinforces the read → predict → verify → restore cycle.

Lab: Add I/O Component End-to-End

  • After: Global Variables & Adding Components
  • Duration: 15 min
  • Walk through adding a new tag for an unused I/O point: create tag, map to physical channel, write a simple rung, download, test with physical device.
  • Students follow along on laptops, replicating the tag and rung. Each pair tests their logic on the bench — the capstone integrative activity.

Quiz

  • A TON timer has a preset of 5000ms and the accumulator shows 5000ms. Is the DN (Done) bit ON or OFF?
  • OFF — the timer is still counting | ON — the accumulator has reached the preset | It depends on the rung state | OFF — 5000ms means the timer has reset

Quiz

  • What is the difference between OTE (Output Coil) and OTL (Output Latch)?
  • They are the same | OTE turns off when the rung loses power; OTL stays on until an OTU unlatch instruction | OTL is faster than OTE | OTE is used for digital, OTL for analog

Quiz

  • Before changing servo motor parameters on a production machine, what should you do?
  • Just make the change — parameters auto-revert on restart | Compare the current values to the documented values and backup the program first | Switch the PLC to PROGRAM mode | Disconnect the encoder
